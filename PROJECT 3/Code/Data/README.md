# Data Directory

Required CSV files for the project.

## 1. Source
**Kaggle Dataset:** [Football Data from Transfermarkt](https://www.kaggle.com/datasets/davidcariboo/player-scores)

## 2. Required Files
Download and place these 3 files in this directory:

1. **`players.csv`**  
   *Player info (DOB, height, etc.)*
2. **`player_valuations.csv`**  
   *Market value history*
3. **`game_events.csv`**  
   *Match events (goals, cards, etc.)*

> **Note:** Ensure filenames match exactly.
